# Check if a File is a FLAC File

Check if a File is a FLAC File

## Usage

``` r
pam_is_flac(path)
```

## Arguments

- path:

  Character. File path or vector of paths.

## Value

Logical scalar or vector.

## Examples

``` r
pam_is_flac(c("a.flac", "b.wav"))
#> Error in pam_is_flac(c("a.flac", "b.wav")): could not find function "pam_is_flac"
```
