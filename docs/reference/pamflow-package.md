# pamflow: End-to-End Passive Acoustic Monitoring Workflow

Tools for passive acoustic monitoring projects, from raw recordings to
data ready for ecological analysis. Standardizes and checks field
recordings, runs 'BirdNET' (Kahl et al. 2021
[doi:10.1016/j.ecoinf.2021.101236](https://doi.org/10.1016/j.ecoinf.2021.101236)
) through its Python package, cleans and validates detections, and
computes soundscape indices. Builds detection histories, count histories
and input for occupancy and abundance models, summarizes activity
patterns and species richness, and writes HTML, PDF and Excel reports.
Optional Shiny apps support standardization, validation and annotation,
and the training of custom 'BirdNET' classifiers.
